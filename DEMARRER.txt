CE PAQUET REMPLACE LE MIROIR : INSTALLATION NEUVE SANS ANCIENNE VM

1. Ajouter tous les fichiers de ce dossier à la racine de SOC_Lionel_EDV.
   Remplacer deploy_soc.sh et README.md. Ajouter autonome.py, infrastructure.py,
   provision.py, transfert.py, agent_windows.ps1, templates/, tests/ et .gitignore.
2. Sur une VM Ubuntu 24.04 x86_64 neuve, suffisamment dimensionnée :

   git clone https://github.com/Liocode2003/SOC_Lionel_EDV.git
   cd SOC_Lionel_EDV
   sudo bash deploy_soc.sh

3. Répondre aux questions initiales (IP, interface, clés API, SMTP et cibles).
4. Le programme déroule les installations et les initialisations.
5. Consulter son résultat. Un échec arrête la chaîne sans déclarer un succès.
   Après diagnostic : sudo bash deploy_soc.sh --reprendre

Ne jamais publier /opt/soc/autonome : ce dossier contient les secrets générés.
Le script n'a pas encore été exécuté sur une VM neuve pendant sa préparation.
Onze tests hors ligne passent. La première installation réelle reste à valider.

Les serveurs Windows/Odoo restent à raccorder ; lire README.md.
Le test de mail attend ensuite une vraie décision humaine.
